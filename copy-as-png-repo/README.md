# Copy as PNG

Obsidian plugin: copies the active note's Reading View — Mermaid diagrams,
syntax-highlighted code blocks, embedded images, everything — to the
clipboard as a PNG.

## How it works

The note is rendered off-screen in a hidden container styled to match
Obsidian's real `.markdown-reading-view` DOM (so theme CSS, snippets, and
custom fonts resolve exactly as they do on screen), then rasterized with
[`modern-screenshot`](https://github.com/qq15725/modern-screenshot) and
copied to the clipboard as a PNG `Blob`.

Two details that took a few rounds to get right (see `src/main.js` for the
inline comments):

- **Content height is measured from the children, not the container.**
  `measureContentHeight()` walks the container's direct children and takes
  the furthest-down bottom edge, then pins that exact height on the content
  element before capture. Trusting the container's own `getBoundingClientRect()`
  left a leftover blank band at the bottom in some themes, because Obsidian's
  real `.markdown-reading-view` CSS can carry a `min-height: 100%` rule that
  inflates a `position: fixed` element's height to the viewport regardless of
  actual content.
- **The crop reference color is sampled from the canvas itself.** After
  rendering with extra bottom headroom (to give reflowed text room to grow),
  the crop scans upward for the last non-background row — comparing against
  the canvas's own bottom-right pixel (guaranteed background) rather than a
  `--background-primary` CSS value resolved separately, which can drift from
  what was actually painted.

## Project layout

```
copy-as-png/
├── src/main.js       # plugin source — edit this
├── dist/main.js      # built output — what you install, generated by esbuild
├── manifest.json     # Obsidian plugin manifest
├── esbuild.config.mjs
└── package.json
```

## Build

```sh
npm install
npm run build   # writes dist/main.js
```

The build is intentionally **not minified** — `dist/main.js` stays readable
and debuggable straight from Obsidian's DevTools.

## Install in Obsidian

Copy `dist/main.js` and `manifest.json` into:

```
<vault>/.obsidian/plugins/copy-as-png/
```

Then enable **Copy as PNG** under Settings → Community plugins.

## Usage

Right-click inside an open note (or on a note in the file explorer) →
**Copy note as PNG**. Also available as a ribbon icon.

Desktop only (uses the Clipboard API with an image `Blob`).
